# Focus On Your Work

生産性を上げるために、指定した URL へのアクセスをブロックして拡張内のページへリダイレクトするブラウザ拡張です。ツールバーアイコンのクリックで有効/無効を切り替えられます。Chrome/Firefox の両方で動作します（Manifest V3）。

## 使い方

1. ブラウザの拡張機能の管理画面を開き、デベロッパーモードでこのフォルダ（work-focus）を読み込みます。
   - Chrome: chrome://extensions → デベロッパーモード → パッケージ化されていない拡張機能を読み込む → このフォルダを選択
   - Firefox: about:debugging#/runtime/this-firefox → 一時的なアドオンを読み込む → manifest.json を選択
2. 拡張の「詳細」→「拡張機能のオプション」を開き、ブロックするドメインを入力して「追加」を押します。登録したドメインは一覧の「編集」「削除」で変更できます（変更はすぐに保存されます）。
   - `http` / `https` とサブドメイン（`www.` など）は自動で対象になるので、`youtube.com` のように書くだけで構いません。
   - `x.com/home` のようにパスを付けると、そのパスで始まるページだけをブロックします。
   - ワイルドカード: `*`（任意の文字列）と `?`（任意の 1 文字）が使用できます。
   - 正規表現: `/regex/` の形式で書くと、URL 全体に対する正規表現として扱います。
   - インストール直後と「設定をリセット」のあとは、`x.com`・`posfie.com`・`togetter.com` が登録された状態になります。
3. ツールバーアイコンをクリックすると有効/無効を切り替えられます。ON のとき、マッチしたページは拡張内のブロックページにリダイレクトされます。
   - ブロックページには、元のページへのリンクとそのページのタイトルが表示されます。
4. オプションページの「ブロックしたドメイン」に、ドメインごとのブロック回数がランキングで表示されます。「統計をリセット」で記録を削除できます（「設定をリセット」では統計は消えません）。

### ブロックが動作しないとき（Firefox）

Firefox では、サイトへのアクセス権限をユーザーが外せます。拡張メニューの「データの取得と変更を許可する条件」が「クリック時のみ」になっていると、ブロックは動作しません。権限が無いとオプションページの上部に警告が出るので、「すべてのサイトへのアクセスを許可」を押してください（インストール・更新時に権限が無ければオプションページが自動で開きます）。

about:debugging の「一時的なアドオン」として読み込んだ場合は、再読み込みのたびに権限が外れることがあります。

## 例

```
youtube.com
x.com/home
*/chatgpt/*
/^https?:\/\/news\.example\.com\/.*$/
```

以前の `*://*.youtube.com/*` のような書き方で保存したパターンは、オプションページを開いたときに `youtube.com` の形へ自動で書き換えられます。

## 技術メモ

- declarativeNetRequest の動的ルールでリダイレクトします。
- パターンは `shared.js` の `patternToRegex` で URL 全体に一致する正規表現に変換します（例: `youtube.com` → `^https?://(?:[^/?#]*\.)?youtube\.com(?::\d+)?(?:[/?#].*)?$`）。ホスト部分のワイルドカードは `/` `?` `#` をまたぎません。
- DNR が使えない環境やルールの適用前に備えて、content script による早期リダイレクト（document_start）も用意しています。
- 元の URL は `blocked.html#<元のURL>` の形でブロックページに渡します。DNR では `regexSubstitution` の `\0`（一致した部分全体）を使うため、パターンを `^.*(?:…).*$` で包んで URL 全体に一致させています。
- ブロックページは元の URL を Cookie なしで取得し、`<title>` を表示します。外部のページから任意の URL を取得させないよう、取得するのはブロック対象のパターンに一致する URL だけです。
- ブロックの記録は `storage.local` の `stats` キーに保存し、外部には送信しません。
  - `history`: 直近 1000 件の `{ time, url }`（古いものから削除）
  - `domains`: ドメインごとの累積回数（`www.` は除いて集計）
  - `hours`: 0〜23 時ごとの累積回数（現在は記録のみで、画面には表示していません）
  - ブロックページが background にメッセージを送り、background が書き込みを順番に処理します。ブロック対象のパターンに一致しない URL や、再読み込み・戻る/進むで開き直した場合は記録しません。
- パターンの解釈と設定の読み込みは `shared.js` にまとめ、background・content script・オプションページ・ブロックページで共有しています。
- アイコンのクリックで `enabled` をトグルし、ON のときはツールバーアイコンが赤（`icons/icon-red-*.png`）に切り替わります。

## 配布用パッケージの作成

この拡張はビルド不要ですが、配布やストア提出のために ZIP/XPI を作成できます。

手順（リポジトリのルートで実行）:

```
npm run build
```

出力先:

- `dist/work-focus.zip`（Chrome ウェブストアや手動配布向け）
- `dist/work-focus.xpi`（Firefox Add-ons 向け）

備考:

- macOS/Linux の標準 `zip` コマンドを使用します（Windows は Git Bash などで実行してください）。
- アーカイブのルート直下に manifest.json などのファイルが入る形で圧縮されます。
- パッケージの manifest からは、それぞれのブラウザが使わないキー（Chrome 用では `background.scripts` と `browser_specific_settings`、Firefox 用では `background.service_worker`）を取り除きます。
